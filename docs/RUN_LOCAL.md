# Local Laptop Running of Pifire for Debugging

## Overview

This branch provides appropriate settings for running Pifire locally on a laptop for debugging purposes.  This document summarizes the commands and general instructions for performing this local run and the clean-up afterwards.

## Set up

To prepare to run Pifire locally, 3 powershell instances are required.
1. Redis Server
2. Web app ------------> navigate to Pifire repo folder
3. Control process ----> navigate to Pifire repo folder

## Command List

| Command                               | Purpose                                   | Notes                                                               |
|---------------------------------------|-------------------------------------------|---------------------------------------------------------------------|
| **redis-server --port {server_num}**  | Initialize redis server at desired port   | port 6380 recommended if 6379 in use (Ctrl+c) to end process        |
| **python app.py**                     | Launch webapp                             |                                                                     |
| **python control.py**                 | Launch control process                    |                                                                     |

## Recommended Order of Operations

1. Open needed powershell instances
2. Start redis server
3. Launch web app
4. Launch control process
5. Open web app at localhost:{port} (5000)

## Clean-up

To stop the python processes, use the powershell command (separate instance): **Get-Process python | Format-Table Id,ProcessName,Path** from the Pifire repo folder.  Then use **Stop-Process -Id <PID> -Force** for each of the process IDs in the table generated by the first command.
